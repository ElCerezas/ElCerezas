## ⭐ Featured project: Matasanos

**Online multiplayer party game** · Unity / C# · Team project · Vertical slice
🏆 **Technical Excellence award at TecnoGames 2026**

**The challenge: synchronising physics in an online party game.**
When several players can grab, throw and hit the same objects, physics easily go out of sync between clients.

**How we solved it:** we distributed network *ownership* so that the player who grabs an object becomes its owner. Physics are then calculated only by that owner, which gives every object a single source of truth.

**My role: programmer.**
- Designed the code architecture to be **modular**, so features could be added and changed without breaking the rest.
- Built the **physics, grabbing and hitting systems**.
